# balatro-cloverpit-mod
Balatro mod that adds in elements from Cloverpit, including:
- 152 new Jokers
- 19 new decks
- 8 new vouchers
- 41 new consumables
- 2 new enhancements
- 7 new editions

## Requirements
This mod requires these mods to function:
- Lovely - [Download here](https://github.com/ethangreen-dev/lovely-injector/releases/tag/v0.10.0)
- Steamodded - [Download here](https://github.com/Steamodded/smods/releases/tag/26.1002.0)
